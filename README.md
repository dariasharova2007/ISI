# isi — сайт-лендинг

Одностраничный сайт **isi** — автоматизация малого бизнеса в Варшаве: Telegram-боты, Google Таблицы и AI, которые берут на себя рутину.

- Чистый HTML + CSS + немного JS, без сборщиков и фреймворков.
- 4 языка: RU / UA / PL / EN. По умолчанию — язык браузера (uk → UA, pl → PL, en → EN, иначе RU); выбор запоминается в браузере.
- Все кнопки ведут в Telegram: https://t.me/samuraeessa

## Файлы

| Файл | Что внутри |
|------|-----------|
| `index.html` | Разметка страницы (русский текст по умолчанию) |
| `style.css`  | Стили (mobile-first) |
| `script.js`  | Переводы на 4 языка, переключатель языка, анимации при прокрутке |

Чтобы поменять текст — правьте словарь `I18N` в `script.js` (ключи совпадают с атрибутами `data-i18n` в `index.html`). Русский текст стоит поправить в обоих местах.

Посмотреть локально: просто откройте `index.html` в браузере.

## Как включить GitHub Pages

1. Загрузите файлы в репозиторий на GitHub (`index.html` должен лежать в корне).
2. Откройте репозиторий → **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/` (ссылка появится там же, в Settings → Pages).

Свой домен (например, `isi.pl`) можно подключить в том же разделе, в поле **Custom domain**.
